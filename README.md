# زياراتي — Ziyarat

تطبيق iPhone لإنشاء **تقارير الزيارات الإشرافية** على ورقة A4 رسمية وتصديرها PDF.

## المزايا

- **أسئلة من إنشائك**: أنت تحدد نوع كل سؤال — اختيار واحد، اختيار متعدد، نص حر، أو تقييم بالنجوم.
- **خيارات جاهزة**: مطبق / غير مطبق، نعم / لا، ممتاز … إلخ، مع إمكانية تعديلها بالكامل.
- **ملاحظة + صور لكل سؤال**: الصور دائماً آخر خانة في السؤال.
- **ترتيب تلقائي على ورقة A4**: الأسئلة والأجوبة والصور تُوزَّع على الصفحات تلقائياً؛ الصورة تظهر **كاملة** وتنتقل للصفحة التالية إذا لم تكفِ المساحة.
- **ترويسة رسمية بتحكم كامل**: الشعار (الحجم والموضع والشفافية)، اسم المملكة، الوزارة، الإدارة، القسم، أسطر الرقم والتاريخ، 4 أنماط توزيع.
- **الخطوط والألوان والهوامش والإطار** قابلة للتعديل، مع معاينة مباشرة بمقاس A4 الحقيقي.
- **التاريخ هجري وميلادي** واسم اليوم تلقائياً، ووقت الزيارة اختياري.
- **نماذج أسئلة** تُحفظ وتُعاد استخدامها في كل زيارة.
- **تصدير PDF** ومشاركته من التطبيق مباشرة، مع ترقيم الصفحات والتوقيعات.

## التقنيات

- SwiftUI (iOS 17+)، MVVM، `async/await`
- تخزين محلي JSON + ملفات الصور داخل مجلد المستندات (لا يُرسل شيء لأي سيرفر)
- بناء PDF عبر `ImageRenderer` + `CGContext` بمقاس A4 الحقيقي (595.3 × 841.9 نقطة) — النص يبقى نصاً داخل الملف
- محرك تقسيم صفحات يقيس كل كتلة بـ `UIHostingController` قبل الرسم

## بنية المشروع

```
Ziyarat/
├── App/            نقطة الانطلاق والتبويبات
├── Models/         Question, Visit, LetterheadSettings
├── Storage/        AppStore (المصدر الوحيد للحقيقة) + ملفات وصور
├── Report/         كتل المحتوى + محرك الصفحات + بناء PDF
├── Views/          شاشات الزيارات والأسئلة والنماذج والترويسة
└── Support/        التواريخ العربية والخطوط
```

## البناء

المشروع يُولَّد بـ [XcodeGen](https://github.com/yonaskolb/XcodeGen) من `project.yml`:

```bash
brew install xcodegen
xcodegen generate
open Ziyarat.xcodeproj
```

### البناء التلقائي على GitHub

كل دفعة على `main` تبني ملف **IPA غير موقّع** عبر GitHub Actions (`.github/workflows/ios.yml`)، وتجده في Artifacts.
وعند إنشاء وسم (tag) يبدأ بـ `v` يُنشأ Release ويُرفع الملف فيه.

للتثبيت على الجهاز: Sideloadly أو AltStore، أو افتح المشروع في Xcode ووقّعه بحسابك.
